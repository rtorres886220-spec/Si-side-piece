Sidekick Chrome Extension Privacy Policy

Effective Date: October 2026 • Version 1.1.3
Single-Purpose Statement: Sidekick is an AI-powered browser companion that grounds generative responses in your active browser tab, highlights cited passages in the page, and executes user-approved UI actions via Chrome DevTools Protocol.

1. Data Minimization & Local-First Architecture

Sidekick adheres strictly to the principle of data minimization and local execution:

  • No Remote Tracking or Telemetry: Sidekick contains zero analytics, tracking beacons, fingerprinting scripts, or third-party advertising SDKs.
  • Client-Side Storage & Full User Control: Your Gemini API key, user preferences, and chat history are saved exclusively in your browser's local sandbox via chrome.storage.local. You can permanently wipe all conversation history at any time using the "Clear All History" feature.
  • Zero Server-Side Retention: Sidekick does not run background databases that harvest or store your browsing history. When Tab Reading is toggled off, zero page text, titles, URLs, or selections are transmitted to the AI service.

2. Defense-in-Depth Sanitization & PII Redaction

Before any webpage text is transmitted to the AI model for analysis, Sidekick runs an automated client-side sanitization pipeline directly on your device:

  • Automatic PII Redaction: Credit card numbers (validated via the Luhn algorithm), American Express cards, Social Security Numbers (SSNs), IBAN bank accounts, and Bearer / JWT authentication tokens are scrubbed and replaced with safe redacting tags.
  • Off-Screen & Invisible DOM Stripper: Hidden elements, invisible text traps, zero-width characters, and Unicode tag characters are stripped to defend against prompt injection attacks.
  • Strict Delimited Enclaves: Page context and active selections are wrapped in cryptographic delimiter tokens (<<<UNTRUSTED_CONTENT_uuid>>>) to isolate untrusted page text from AI instructions.

3. Permissions Justifications (Chrome Web Store Standard)

Sidekick requests only the minimum set of permissions necessary to deliver its core features:

  • sidePanel: Enables Sidekick to reside conveniently alongside your active web tabs in Google Chrome's native side panel.
  • tabs & activeTab: Used exclusively to identify the current tab's URL and title, ensuring the assistant knows which page you are discussing.
  • webNavigation: Observes browser navigation commits to seamlessly clear stale page state and synchronize context with newly navigated tabs.
  • <all_urls>: Required in Manifest V3 to read visible webpage text when you ask questions about the page and to highlight cited passages upon click.
  • scripting: Used dynamically to locate and highlight verbatim citations when you click on quote citations in the conversation thread.
  • storage: Stores your Gemini API key and chat history locally on your device.
  • debugger (Option B CDP): Used strictly for ephemeral, just-in-time dispatch of true hardware mouse clicks and keystrokes for user-authorized automation tasks. The debugger attaches only for milliseconds during approved steps and detaches immediately.

4. Third-Party AI Services

When you ask a question or request page analysis, the sanitized text and your prompt are transmitted via secure HTTPS directly to Google's official Gemini API (https://generativelanguage.googleapis.com) using your personal Gemini API key. Data processed through Google AI Studio is governed by Google's terms and privacy policies.

5. Mandatory Human-in-the-Loop Security Gate

Sidekick operates under strict user control. High-risk actions (such as submitting forms, navigating to external domains, confirming cancellations, making payments, placing orders, deleting accounts, or authorizing access) trigger a mandatory, visual confirmation modal displaying the target action, selector, verified live element, and coordinates. Actions are aborted unless you explicitly click "Approve". Automation is blocked on sensitive platforms including major banking institutions, financial portals, credential managers, administrative cloud consoles, and government services via an immutable deny-list.

For questions or compliance audits regarding this Privacy Policy, please visit the official Sidekick project dashboard or repository.
